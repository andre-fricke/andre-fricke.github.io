# Empfehlungen und Nachweise einbinden

1. PDF-Dateien in diesen Ordner kopieren. Aussagekräftige, URL-taugliche Namen verwenden, zum Beispiel `empfehlung-db-2026.pdf`.
2. In `script.js` oben den Eintrag unter `RECOMMENDATIONS` anpassen.
3. Bei `file` den relativen Pfad eintragen, zum Beispiel `assets/recommendations/empfehlung-db-2026.pdf`.
4. `source`, `title` und `description` auf Deutsch (`de`) und Englisch (`en`) ausfüllen.

Sobald ein `file` gesetzt ist, wird aus dem Platzhalter automatisch eine anklickbare Karte mit PDF-Vorschau.
